# Domain 1: Cloud Concepts

## What This Domain Covers in AZ-900

This domain covers fundamental cloud computing concepts that form the foundation for understanding Azure and cloud services. It includes:

- Cloud computing basics and definitions
- Cloud service models (IaaS, PaaS, SaaS)
- Cloud deployment models (Public, Private, Hybrid, Community)
- Cloud economics and benefits (CAPEX vs OPEX, Total Cost of Ownership)

## Why It Matters for the Exam

This domain represents **25-30%** of the AZ-900 exam. Understanding these fundamental concepts is critical because:

- All Azure services are built on these cloud principles
- Exam questions often test your ability to distinguish between service models
- Understanding deployment models helps in scenario-based questions
- Cloud economics questions appear frequently

## Common Misconceptions

1. **IaaS vs PaaS confusion**: Many candidates struggle to distinguish when to use IaaS vs PaaS. Remember: IaaS gives you control over the OS and applications; PaaS manages the OS for you.

2. **Hybrid cloud definition**: Hybrid cloud is not just "using multiple clouds" - it requires orchestration between on-premises and cloud environments.

3. **CAPEX vs OPEX**: Cloud computing shifts costs from CAPEX (capital expenditure) to OPEX (operational expenditure), but this doesn't mean it's always cheaper - it's about flexibility and scalability.
