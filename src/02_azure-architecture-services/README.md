# Domain 2: Azure Architecture and Services

## What This Domain Covers in AZ-900

This domain covers Azure's core architectural components and services. It includes:

- Core architectural components (Regions, Availability Zones, Resource Groups, Subscriptions)
- Compute services (Virtual Machines, App Services, Container Instances, Functions)
- Networking services (Virtual Networks, Load Balancers, VPN Gateway, Azure DNS)
- Storage services (Blob Storage, File Storage, Queue Storage, Table Storage)

## Why It Matters for the Exam

This domain represents **35-40%** of the AZ-900 exam - the largest domain. Understanding these services is critical because:

- Most exam questions focus on Azure services and their use cases
- You need to know which service to use for specific scenarios
- Understanding Azure's global infrastructure is fundamental
- Service comparisons and differences are frequently tested

## Common Misconceptions

1. **Regions vs Availability Zones**: Regions are geographic areas; Availability Zones are physically separate datacenters within a region. Not all regions have Availability Zones.

2. **Resource Groups vs Subscriptions**: Resource Groups are logical containers for resources; Subscriptions are billing boundaries. Resources can be moved between Resource Groups but not between Subscriptions easily.

3. **Storage account types confusion**: Blob Storage is for unstructured data; File Storage is for file shares; Queue Storage is for messaging; Table Storage is for NoSQL data.
