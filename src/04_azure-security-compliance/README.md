# Domain 4: Azure Security, Privacy, Compliance, and Trust

## What This Domain Covers in AZ-900

This domain covers Azure's security, privacy, compliance, and trust features. It includes:

- Shared responsibility model (what Microsoft manages vs what you manage)
- Azure security tools (Azure Security Center, Azure Sentinel, Key Vault, Network Security Groups)
- Compliance offerings (Compliance Manager, Service Trust Portal, Compliance certifications)
- Trust and privacy (Data residency, Data encryption, Privacy statement)

## Why It Matters for the Exam

This domain represents **20-25%** of the AZ-900 exam. Understanding these concepts is critical because:

- Security is a top concern in cloud adoption
- Compliance questions test your understanding of Azure's certifications
- The shared responsibility model is fundamental to cloud security
- Security tools and their use cases are frequently tested

## Common Misconceptions

1. **Shared responsibility model**: Many candidates think Microsoft manages everything in the cloud. The reality is that Microsoft manages the cloud infrastructure, but you're responsible for your data, applications, and access control.

2. **Security Center vs Sentinel**: Security Center is for security posture management and threat protection; Sentinel is for Security Information and Event Management (SIEM) and Security Orchestration, Automation, and Response (SOAR).

3. **Compliance certifications**: Azure has many compliance certifications, but that doesn't mean your application is automatically compliant - you must configure and use Azure services correctly.
