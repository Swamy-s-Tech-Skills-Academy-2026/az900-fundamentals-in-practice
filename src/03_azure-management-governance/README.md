# Domain 3: Azure Management and Governance

## What This Domain Covers in AZ-900

This domain covers how to manage and govern Azure resources. It includes:

- Identity and access management (Azure AD, RBAC, MFA)
- Cost management (Pricing calculator, Cost Management, Reservations)
- Governance features (Azure Policy, Resource Locks, Tags, Management Groups)
- Resource management tools (Azure Portal, Azure CLI, Azure PowerShell, Cloud Shell)

## Why It Matters for the Exam

This domain represents **10-15%** of the AZ-900 exam. Understanding these concepts is important because:

- Security and governance are critical in cloud environments
- Cost management questions appear frequently
- You need to know which tool to use for specific management tasks
- RBAC and access control are fundamental security concepts

## Common Misconceptions

1. **Azure AD vs Active Directory**: Azure AD is not the same as on-premises Active Directory. It's a cloud-based identity service, not a domain controller in the cloud.

2. **RBAC roles**: RBAC is about permissions, not authentication. Authentication is handled by Azure AD; authorization is handled by RBAC.

3. **Resource Locks vs Azure Policy**: Resource Locks prevent accidental deletion/modification; Azure Policy enforces organizational standards and compliance.
